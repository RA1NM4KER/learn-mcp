# Code of Conduct

## Our standard

We want this project to be a welcoming, useful place for people of every background and experience level.

Examples of positive participation include:

- communicating with empathy and respect;
- giving specific, constructive feedback;
- respecting privacy, consent, and differing viewpoints;
- taking responsibility for mistakes and correcting them;
- focusing discussion on what benefits the project and its users.

Unacceptable behaviour includes harassment, discrimination, threats, sexualized attention, deliberate intimidation, publishing another person’s private information, or sustained disruption of project discussions.

## Scope

This code applies in repository issues, pull requests, discussions, and other spaces where someone is representing this project.

## Enforcement

Project maintainers may edit or remove contributions that violate this standard and may temporarily or permanently restrict participation. Enforcement decisions will consider context, impact, and whether behaviour is repeated.

Report conduct concerns privately through the maintainer’s public GitHub profile. Do not include sensitive conduct reports in a public issue. Reports will be reviewed in good faith with appropriate confidentiality.
